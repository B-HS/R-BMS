# rbms docs

최종 갱신 2026-10-15 · 대응 커밋 ea698a9

Project documentation for [rbms](../README.md), a Rust port of the reference implementation's BMS-player PLAY core plus the `web/` IR server. The client is released as `v0.1.4` (published 2026-10-15; details in [ci-release.md](ci-release.md)).

A fresh session starts with [HANDOFF.md](HANDOFF.md) (the latest session snapshot, overwritten each session: done / in progress / not started, decisions, rules, open questions, next steps), then [PROCESS.md](PROCESS.md) and the documents they link.
