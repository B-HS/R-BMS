# rbms UI 디자인 스펙 — SELECT / PLAY / RESULT (1280×720, rects+text 전용)

## 0. 렌더 모델·전역 규약 (코드 정합)

실제 `rbms-render` 프리미티브에 맞춰 작성한다. **사각형 채움**과 **텍스트**만으로 구성한다.

- 프리미티브: `clear(Color)`, `fill_rect(Rect{x,y,w,h}, Color)`, `draw_text(x,y,scale,color,str)`(좌상단 기준), `draw_text_centered(cx,y,...)`, `draw_text_right(right_x,y,...)`. Color는 `{r,g,b,a:u8}` (알파 블렌딩 됨).
- `scale` 단위: 기본 글자 약 14px 높이 × scale. 본 스펙의 `s=` 값은 그 scale이다 (s2.0≈28px, s5.0≈70px).
- 좌표공간 **1280×720 고정**. 모든 수치는 이 좌표계 절대 픽셀. 리사이즈 리플로우 없음(논리 고정).
- 깊이는 z-buffer가 없으므로 **그리는 순서 = 레이어**. 항상 `clear → 패널 배경 rect → 게이지/그래프 rect → 노트 → 커버 rect → 텍스트` 순.
- **반투명 패널**: `Color{a:160~200}`인 어두운 사각형을 텍스트 뒤에 깔아 가독성 확보(알파 블렌딩 지원됨).
- 색 팔레트(코드 상수 재사용 + 추가):
  - 배경 `BLACK(0,0,0)` / 패널 `(18,18,24)~(28,28,36)` / 텍스트 `WHITE(235,235,235)` / 보조 `GRAY(90,90,100)`
  - 흰건반 레인 `(18,18,24)` · 파란건반 레인 `(14,16,26)`(살짝 더 푸름) · 스크래치 `(26,14,14)`(살짝 붉음)
  - 노트: 흰건반 `(220,220,230)` · 파란건반 `BLUE(70,130,230)` · 스크래치 `RED(230,70,70)` · LN body `(70,180,120) a:200`
  - 판정선 `JUDGE_LINE(200,40,40)`
  - 그래프: current=`CYAN(64,192,192)` · best=`GREEN(70,220,120)` · target=`(230,70,120)`(마젠타 계열)
  - 클리어램프: FAIL `GRAY` · ASSIST `(180,120,220)` · EASY `(70,200,120)` · NORMAL `(235,235,235)` · HARD `(230,150,60)` · EX-HARD `RED` · FULLCOMBO `(90,210,230)` · PERFECT `(255,230,140)`

> **rects/text로 가능 vs 근사**: 막대그래프·게이지바·임계선·레인·노트·판정선·램프(작은 사각형)·텍스트 수치는 **그대로 가능**. 곡선 score-curve 그래프는 **막대/계단(꺾은선 대신 세로 막대 시퀀스)으로 근사**. 원형 램프·radar(펜타곤) note-distribution·BGA 동영상·캐릭터 일러스트는 **불가 → 사각형 LED·막대 5축·정적 색면으로 대체**.

### 2.2 플레이 필드 — 베젤(천장)에서 노트 emerge

이 부분이 요구의 핵심. **노트가 윈도우 가장자리(y=0)가 아니라 프레임 안쪽에서 나타나게** 한다.

- 필드 외곽선: 위에 본 `playfield.rs`처럼 top(=field_top=90)·judge_y·좌·우에 `outline` 사각형(두께 t=2)으로 **닫힌 프레임**을 그린다. 천장이 y=90에 있으므로 노트 스크롤 영역은 `[90, 620]`.
- 레인: 7키(흰/파 교차) + 스크래치. `lane_w = field_w/8 = 45`. 스크래치(스크 side에 따라 좌 또는 우 끝) `45`, 키1~7 각 `45`. 흰건반 레인색·파란건반 레인색·스크 레인색은 §0. 레인 사이 1px 구분선 `(40,40,52)`.
- 노트: 각 노트는 레인폭 `lane_w−2` × 높이 `10`(스크는 높이 `14`)인 채움 사각형. y는 스크롤 함수(visible/constant)로 `[90,620]`에 매핑. LN은 head 사각 + body(반투명 긴 사각, `LN body`색) + tail.
- **판정선**: `fill_rect(field_x0, 620, field_w, 4, JUDGE_LINE)` (코드의 judge_y).
- **레인 커버(SUDDEN+) = 천장에서의 emerge 강화**: `render_lane_cover(cover_frac)`로 필드 상단 `cover_frac`만큼을 **불투명 사각형**(`(0,0,0) a:235`)으로 덮는다. 베젤(y<90)은 항상 불투명, 그 아래 cover까지 합쳐 노트는 "프레임 천장 + 커버 경계 아래"에서 나타난다. LIFT는 판정선·게이지를 위로 올린 만큼 전 영역 y오프셋.
- 키 빔: 키 눌림 시 해당 레인 `field_top..judge_y` 폭 전체에 반투명 세로 사각(레인색 밝게 a:90).

### 2.3 라이브 스코어 그래프 (중앙, 740,120 / 150×500) — IIDX 페이스메이커

세로 그래프. **아래=0점, 위=max EX**. y축 매핑: `bar_y(ex) = 120 + 500*(1 - ex/maxEX)`.

- 그래프 배경 패널 `(16,16,22)`.
- **랭크 밴드 임계 가로선**(A/AA/AAA…): 각 등급 임계 EX비율 ratio에 대해 `y=120+500*(1-ratio)`에 `150×1px` GRAY 가로선. 라벨은 우측 끝 바깥 `draw_text(895, y-6, s1.0, GRAY, "AAA")`. 최소 A(6/9)·AA(7/9)·AAA(8/9)·MAX(1.0) 4선. (코드 `dj_rank` 임계 재사용)

  - x=800 BEST(GREEN): 베스트 EX 비례 높이.
  - x=852 TARGET(마젠타): 타깃/라이벌 EX 비례 높이.
- **델타 표시**(현재−타깃, 현재−베스트): 그래프 상단 `740,98`에 `draw_text`로 `vs BEST +120 / vs TGT -45`. 양수 GREEN·음수 RED. 막대 머리 옆에도 작은 수치 옵션.

> 곡선이 아니라 **현재값을 막대로 즉시 반영**(IIDX 페이스메이커가 본래 막대형). 진행률 곡선이 필요하면 그래프 폭을 가로 시간축으로 바꿔 세로 1px 막대를 매 구간 추가하는 "계단 막대" 근사가 가능하나, 기본은 3-막대 페이스메이커로 둔다.

### 3.2 DJ-LEVEL 랭크 (40,90 / 360×220)

- 등급 산출: EX% → 9분법(F~MAX). 코드 `dj_rank` 사용.
- `draw_text_centered(220, 130, s8.0, gradeColor, "AAA")` — 거대 글자(≈110px). 등급색: AAA `(255,230,140)`(금)·AA `(220,220,230)`·A `WHITE`·이하 점차 GRAY 톤다운·MAX 특수 `(255,255,200)`.
- 아래 EX% 수치: `draw_text_centered(220, 235, s2.4, gradeColor, "89.42%")`.
- 신기록이면 `NEW RECORD`(s1.6 YELLOW) 깜빡 옵션.

### 3.3 랭크 막대 그래프 (40,320 / 360×120)

- SELECT 1.4와 동일 구조의 **가로 EX 막대 3행**: CURRENT(CYAN)·BEST(GREEN)·TARGET(마젠타), 막대 최대폭 `300`(x=90→390). 9분법 세로 임계선 + A/AA/AAA 라벨. CURRENT가 이번 플레이 결과.

### 3.4 점수 리포트 (40,456 / 420×230)

반투명 패널. 라벨(GRAY,좌 s1.4) + 값(WHITE,우 정렬 s1.8), 행높이 `24`:
- EX SCORE `1666 / 1848`(현재/max, max는 GRAY)
- SCORE(beatoraja식 환산점 또는 생략 가능)
- MAX COMBO `0289 / 1048`
- TOTAL NOTES
- **PGREAT**(값 색 `(255,30,150)` 핫핑크 — IIDX 관례) / GREAT(WHITE) / GOOD(YELLOW) / BAD(ORANGE) / POOR(RED)
- FAST `12` / SLOW `34`(분리 표기)
- 값은 `draw_text_right`로 우측 정렬.

### 3.5 EX 스코어 진행 그래프 (500,90 / 430×300)

- 가로축=곡 진행(0→100%), 세로축=누적 EX. **세로 막대 시퀀스(계단 근사)**: 곡을 N구간(예 64)으로 나눠 각 구간 끝 누적 EX를 `막대폭=430/N, 높이=300*(ex/maxEX)`로 위로. CURRENT=CYAN 막대.
- BEST 라인: 베스트 진행값을 GREEN **1px 가로 점선 대신 얇은 막대 윤곽** 또는 각 구간 상단에 GREEN 1px 마커(꺾은선 불가 → 마커 점 근사).
- 9분법 가로 임계선(A/AA/AAA) GRAY + 라벨.

### 3.6 게이지 추이 (500,404 / 430×120)

- 가로=시간, 세로=게이지 0~100. 구간별 게이지값을 세로 막대(클리어구간 `gauge_color_clear`, 위험 `fail`색)로. 80% 위치에 GRAY 가로 임계선.

### 3.7 클리어 램프 + 결과 (960,90 / 280×200)

- 큰 램프 LED: `fill_rect(1000, 110, 200, 60, lampColor)` + 외곽 outline. (원형 불가 → 사각 LED)
- 상태 텍스트: `draw_text_centered(1100, 185, s3.0, lampColor, "HARD CLEAR" / "FAILED")`.
- 게이지 최종%: `draw_text_centered(1100, 230, s1.8, WHITE, "GAUGE 82%")`.
- 사용 옵션 요약: `RANDOM · H-FIX 3.5 · JUDGE 100%`(s1.2 GRAY).

### 3.8 판정 분포 (960,300 / 280×120)

- early/late 막대: 좌=FAST(CYAN), 우=SLOW(ORANGE) 양방향 막대 또는 PG/GR별 early·late 2색 누적 막대. 중앙 0선 세로 GRAY.

## 4. 구현 가능성 요약 (rects/text 기준)

**그대로 구현 가능**: 모든 패널/배경, 레인·노트·LN·판정선, 가로 게이지 + 임계 틱, 라이브 스코어 3-막대 페이스메이커 + 9분법 임계선·델타, 랭크 막대 그래프, 거대 DJ-LEVEL 텍스트, 점수 리포트 행, 클리어램프(사각 LED), FAST/SLOW 분포 막대, 좌상단 정보, 곡 리스트(상태바+레벨배지+램프 LED).

**막대/색면으로 근사**: score-curve 곡선 → **세로 막대 계단**(RESULT EX진행·게이지추이), best 곡선 → **구간 마커 점**, 원형 클리어램프 → **사각 LED**, note-distribution radar(펜타곤) → **5축 가로 막대 묶음**(SELECT 상세에 옵션).

**불가 → 대체/생략**: BGA 동영상·캐릭터 일러스트·Q-Pro 아바타 → **정적 색면 프레임 + 곡 타이틀 텍스트**. 부드러운 그라데이션 채움 → **2~3단 색띠 사각형** 근사. 글로우/네온 → 미지원(밝은 단색으로 대체).

**핵심 요구 충족 포인트**: (1) 노트는 `field_top=90` 베젤 천장 + `render_lane_cover` 아래에서 emerge — 윈도우 가장자리가 아닌 **닫힌 프레임 안쪽**에서 나온다. (2) 중앙 라이브 스코어 그래프는 9분법 A/AA/AAA 임계 가로선 + CURRENT 막대 성장 + BEST/TARGET 막대 + 델타 텍스트로 IIDX 페이스메이커를 재현한다. (3) 가로 게이지·판정/콤보·BGA·판정카운트는 기존 `hud.rs`/`playfield.rs` 좌표 관례(`judge_y`/`fields`/`gauge_*`/`top_y`)에 직접 매핑되어 추가 프리미티브 없이 구현된다.
