### 2.2 이 조사가 새로 정한 정의 [확인: 정의와 계산]

기호: T = 판정 노트 시각(오름차순, µs), n = 개수, t0 = T[0], t1 = T[n-1] + 1, 활동 구간 span = (t1 - t0)/1e6 초.

| 이름 | 정의 |
| --- | --- |
| 평균 NPS (avg) | n / span. 첫 판정 노트부터 마지막 판정 노트까지의 평균(앞의 무음 도입을 뺌, 첫 노트 시각 중앙값 1.4~1.7초라 영향 작음) |
| 0.5초 격자 r_k | g_k = t0 + 0.5s*k, r_k = count(T in [g_k - 1s, g_k + 1s)) / (min(g_k + 1s, t1) - max(g_k - 1s, t0)) (초). 시간 기준 nps2 이고 활동 구간 끝에서 창을 잘라 나눔 |
| 구간 곡선 (K등분) | 활동 구간을 K=10 또는 20 등분, seg_j = count(T in [t0 + span*j/K, t0 + span*(j+1)/K)). 곡 평균 정규화 = seg_j/(n/K), 최고 구간 정규화 = seg_j/max seg. K=10 은 K=20 의 이웃 두 구간 합 |
| 최대 w초 평균 | max_i count(T in [T[i], T[i]+w))/w, w = 2, 4, 8, 16, 30, 60 (peakRateOf 와 같은 식). 활동 구간이 w초보다 짧으면 비움 |
| 가장 어려운 1분 | 후보 시작 s 는 T[i] + 60s <= t1 인 T[i] 들과 t1 - 60s. count(T in [s, s+60s)) 최대(동률이면 가장 이른 s). μ = count/60. 5초 12구간 rel_j = (count_j/5)/μ |
| 대표(중앙) 1분 | 시작 s = t0 + 5s*m (60초가 활동 구간 안에 들어가는 m)의 노트 수 중앙값에 가장 가까운 창, 같은 방식으로 12구간 정규화 |
| 고점 구간 | r_k >= 0.8*max r 인 연속 격자 점, 간격 2점(1.0초) 이하는 병합, 길이 = 점 수*0.5초. 1분 안에서는 r_k/μ >= 1.25 (강한 고점 1.4) |
| 휴식 | r_k < ρ*avg 인 연속 격자 점(병합 없음), 길이 2초 이상. ρ = 0.5 (휴식), 0.25 (깊은 휴식). 1분 안에서는 r_k/μ < 0.5 (휴식) 또는 < 0.7 (얕은 휴식) |
| 밀도 파동 | 격자 열 r_k(평탄 구간은 가운데 한 점으로 줄임)의 지형 돌출도: 좌우로 더 높은 점을 만나기 전까지의 최저값 중 높은 쪽을 뺀 값. 돌출도가 0.25*avg (또는 0.5*avg) 이상인 봉우리. 1분 안에서는 r_k/μ 기준 |
| 인접 5초 변화 | 1분 12구간의 절대 변화 abs(rel_{j+1} - rel_j) 11개 |
| 고점 노트 | 곡 안 노트 nps2 가 그 곡의 nps2 p90(최근접 순위) 이상인 노트 |
| 노트/행 | n / (서로 다른 판정 노트 시각의 수) |
| 16분 연타 대비 행 밀도 | (n/행 수/span) / (노트 BPM 중앙값/15). 16분 연타의 행/초는 BPM/15 |
| 노트 BPM | createTempoLookup(...).bpmAt(T[i]) (pattern-tags.ts:135)의 노트 기준 분위수 |

### 2.3 통계 처리

- 곡 단위 지표는 대역 안 곡들의 중앙값으로 적습니다(선형 보간 분위수). 사분위가 필요한 곳은 따로 적었고 전체 표는 agg.md 에 있습니다.
- 구간 길이·파동 간격·돌출 크기처럼 한 곡에 여러 개가 나오는 값은 모든 곡의 값을 합쳐(풀링) 분위수를 냅니다.
- 원형 곡선은 1분 12구간 정규화 곡선에 k-means(k-means++ 초기화, 시드 mulberry32(seed*1000 + restart), 20회 재시작, 최대 100 반복, 유클리드 거리, 관성이 가장 작은 것)를 적용했고 군집은 크기순으로 A, B, ... 라벨을 붙였습니다. 소속 비율은 각 곡을 가장 가까운 중심에 배정해 센 것입니다.
- 레벨-밀도 선형 관계는 곡 단위 최소제곱입니다.

### 4.2 읽는 법 (도입 · 전개 · 고점 위치 · 끝)

- 도입 [확인]. K=10 의 첫 구간은 곡 평균의 0.60~0.72배(발광), 0.51~0.60배(Stella), 0.55~0.72배(Satellite)입니다. K=20 으로 보면 첫 5% 가 0.50~0.59(발광)·0.34~0.44(Stella), 둘째 5% 가 0.71~0.82(발광)입니다. 도입은 처음 10% 정도(약 12~13초)에 걸쳐 평균의 절반쯤에서 시작해 오릅니다. 첫 노트는 곡 시작 후 중앙값 1.4~1.7초에 나옵니다.
- 전개 [확인]. 15% 지점부터 70% 지점까지 중앙값 곡선은 0.96~1.13 에서 평탄합니다. 5~6번째 구간은 평균 곡선(0.90~0.97)이 중앙값 곡선(0.96~1.02)보다 낮고 하위 사분위가 0.67~0.83 이라, 곡의 일부(약 4분의 1)에는 중반 휴식이 있습니다. 모양은 대역(레벨)과 거의 무관합니다.
- 고점 위치 [확인]. 곡에서 가장 센 10% 구간은 마지막 10% 에 29~44%, 마지막 30% 안에 63~81%(표본 40곡 이상 대역, 대부분 약 70%) 곡이 있고 첫 30% 안에는 4~15% 입니다. 단일 최고 2초 시점(r_k 최댓값)의 위치 중앙값은 0.82~0.94(곡 후반)입니다. 가장 어려운 1분(6절)이 곡 끝 5초 안에서 끝나는 곡이 40~51%, 15초 안에서 끝나는 곡이 54~62% 입니다.
- 끝 [확인]. 마지막 10% 구간은 1.21~1.28배(발광), 1.19~1.26배(Stella), 1.10~1.26배(Satellite)이고 마지막 5% 구간은 1.21~1.29배(발광 중앙값, 사분위 0.84~1.51)입니다. 끝에서 오르는 폭은 곡마다 큽니다.
- [추측] 도입에서 낮고 끝에서 높은 것은 전주에서 클라이맥스로 밀도를 올리는 BMS 작성 관습의 결과로 보입니다. 이 조사는 음악 구조를 읽지 않았습니다.

- 이 문서의 표는 agg.md 에서 옮겼고, 해설과 9절의 후보값은 같은 표에서 읽은 것입니다.

핵심 계산식:

T = 판정 노트 시각(오름차순), n = |T|, t0 = T[0], t1 = T[n-1] + 1, span = (t1 - t0)/1e6, avg = n/span
r_k = count(T in [g_k - 1s, g_k + 1s)) / ((min(g_k + 1s, t1) - max(g_k - 1s, t0))/1e6), g_k = t0 + 0.5s*k
seg_j = count(T in [t0 + (t1-t0)*j/20, t0 + (t1-t0)*(j+1)/20)), 곡 평균 정규화 = seg_j*20/n
PA(w) = max_i count(T in [T[i], T[i] + w)) / w
minute = argmax_s count(T in [s, s + 60s)), s 는 T[i] + 60s <= t1 인 T[i] 와 t1 - 60s, μ = count/60
rel_j = (count(T in [s + 5j, s + 5(j+1)))/5) / μ, j = 0..11
고점 = runs(r_k >= 0.8*max r) (간격 2점 이하 병합), 휴식 = runs(r_k < 0.5*avg) 길이 2초 이상
파동 = prominence(r_k) >= 0.25*avg (1분 안에서는 r_k/μ)
nps2 분위수는 엔진과 같은 최근접 순위, 대역 통계는 곡별 값의 선형 보간 분위수

## 11. 확인하지 못한 것 · 추측 · 열린 질문

1. 한계 L 의 앵커 [열린 질문]. limit_nps_ex 는 EX 가 기준보다 10%p 떨어진 첫 2-NPS 구간의 아래 끝입니다(web/src/server/service/domain/analysis/weakness-profile.ts:609,620, 04 문서 0절 4번). 그 L 이 실제 곡의 어느 분위에 해당하는지는 사용자 기록이 있어야 알 수 있고 이 조사는 사용자 기록을 읽지 않았습니다. 9.2절은 앵커를 가정한 환산 예일 뿐입니다. 사용자 결정(기본 100~110%, 최고 115~130%)을 어느 앵커에 걸지 정해야 합성기 상수가 정해집니다.
2. 측정 해상도. 격자는 0.5초이고 창은 2초(nps2)입니다. 1초 안 변화(예: 0.375초 단위 교대)와 마디 안 리듬 변화는 이 통계에 나타나지 않습니다. 합성기의 burst(1박 교대) 같은 짧은 규모의 실제 모양은 확인하지 못했습니다.
3. 표본 편향 [추측]. 라이브러리는 한 사용자가 모은 7키 7,904곡입니다. 발광 표는 100% 이지만 Stella 14%, Satellite 12% 라 두 표의 고난도 쪽 표본이 작습니다(st9~12 41곡, st12 1곡). 표 밖 6,226곡은 출처와 난이도가 섞여 있습니다. BMS 전체의 대표 표본이라고 말할 수 없습니다.
4. LN 곡. 표 곡 대부분은 LN 이 없고(LN 비율 중앙값 0), 7,904곡 중 declared_ln 이 ln 인 곡은 2곡, has_undefined_ln 은 2,317곡입니다. 선언이 없는 LN 끝은 판정 노트로 세지 않았습니다(엔진과 같은 규칙). CN/HCN 으로 플레이하면 판정 노트 수가 늘어 밀도가 달라지는 곡이 있습니다. LN 곡의 흐름은 따로 보지 않았습니다.
5. 가장 어려운 1분의 선택 편향 [확인]. 노트 수가 최대인 1분이라 정의상 곡 후반(끝 5초 안에서 끝나는 곡 40~51%)에 몰리고 곡 평균보다 높습니다. 곡 전체의 끝 상승이 6.2절 중앙값 곡선에 그대로 들어옵니다. 곡 평균 근처의 1분(대표 1분)은 8.2절에 따로 있습니다.
