# 다국어 용어집 (초안) — 영어·한국어·일본어

> 최종 갱신 2026-10-24 · 대응 커밋 `bca5306` 위 I0 작업 트리 · 상태: **초안, 사용자 미확인, 일본어 원어민 감수 전**
> 입력: [다국어 조사](2026-10-24-i18n-survey.md) 3.2절(IIDX 표기 관례)·4.1절 12번(유지 용어)·4.6절(용어집 초안), [다섯 기능 실행 계획](../plan/2026-10-24-five-features-plan.md) 1.2절 결정 Q4(게임 용어 원어 유지)·Q5(한국어 chart = 차트, 일본어 譜面, プレー)·Q6(감수 절차).
> 쓰는 곳: 클라이언트 카탈로그(`rbms_model::translations!`, 번역 단위 I2~I7)와 기본 스킨 `t(key)`(I1·I7), 웹 메시지(WI1~WI4). 번역 단위는 이 문서를 입력으로 받고, 새 용어가 필요하면 쓰기 전에 여기에 먼저 더한다.

## 0. 한눈에

1. 게임 용어(판정, 게이지, 램프, 옵션 이름, 점수 이름, 키 이름)는 세 언어 모두 영어 원어 그대로 둔다. 번역하는 것은 그 용어를 설명하는 문장과 일반 화면 단어뿐이다(Q4).
2. chart 는 한국어 **차트**, 일본어 **譜面**이다(Q5). 한국어는 R-BMS 웹과 맞췄다(웹은 이미 `차트` 를 쓴다).
3. 일본어 play 는 IIDX 식 **プレー** 로 쓴다(プレイ 아님).
4. 언어 이름은 그 언어로 쓴다: `ENGLISH`, `한국어`, `日本語`(설정 LANGUAGE 행과 같다).
5. 근거 약호: [B] beatoraja `UIResources_ja_JP.properties`, [I] IIDX 공식 일본어 도움말, [R] 같은 소유자의 `iidx-rank` 메시지, [N] 나무위키 IIDX 문서, [W] R-BMS 웹, [G] 일반 외래어·일반어(근거 없음). 한국어는 [I] 같은 공식 근거가 없어 모두 초안이다(조사 3.2절).

## 3. 표기 규칙

1. **자리표**: 숫자·이름은 `{0}`, `{1}` 자리표로 넣고, 각 언어가 자기 어순에 맞게 자리를 옮긴다. 세 언어가 같은 자리표 집합을 써야 한다(`rbms_model::translations::catalog_problems` 가 검사).
2. **문장 단위**: 영어 조각을 이어 붙인 문장(조사 2.3절)은 번역하지 않고 문장 전체를 한 항목으로 다시 쓴다. 영어의 단수·복수는 영어 쪽 항목을 둘로 나누고 한국어·일본어는 같은 문장을 두 번 쓴다.
3. **대소문자**: 영어 화면 문구는 지금처럼 대문자 위주다. 한국어·일본어에는 대소문자가 없으므로 원어 용어만 대문자로 남는다.
4. **문체**: 라벨·제목은 명사형(한국어 "설정", 일본어 "設定"). 설명문은 한국어 "~합니다", 안내·요청은 "~해 주세요", 일본어 "です/ます"([R] 의 선례).
5. **일본어 문자 폭**: 영숫자·기호는 반각(`EX SCORE`, `100%`), 문장부호는 전각(`、` `。`), 원어 용어와 일본어 사이에 공백을 두지 않는다(예: `HARDゲージ`). 단 원어 용어끼리는 원래 공백을 지킨다.
6. **한국어 띄어쓰기**: 원어 용어와 한국어 명사 사이는 띄어 쓴다(예: `HARD 게이지`). 숫자 + 단위 명사는 붙인다(예: `차트 12개`).
7. **앞뒤 공백**: 각 언어 문자열의 앞뒤 공백은 영어와 같아야 한다(정렬에 쓰는 공백이 있기 때문, 같은 검사).
8. **번역하지 않는 것**: 곡 제목·아티스트·표 이름·폴더 이름 같은 데이터, 스킨이 주는 글자, 서버가 주는 오류 문구(Q8, 1단계는 서버 한국어 그대로), Discord 상태 문구(Q9, 영어), CLI·stderr 로그.

## 4. 번역 품질 절차 (Q6)

1. 이 용어집을 먼저 확정한다(사용자 검수).
2. 번역 단위가 용어집을 입력으로 받아 초안을 쓴다.
3. 되번역(초안을 영어로 다시 옮겨 의미 비교)으로 1차 점검한다.
4. 한국어는 사용자가 검수한다.
5. 일본어는 원어민 감수가 필요하다. 릴리스 노트로 감수를 요청하되, 게시는 초안 승인 뒤에만 한다.
6. 실제 창에서 세 언어로 캡처해 길이·줄 높이·잘림을 본다(조사 4.5절 7번, 하니스는 CJK 를 그리지 못한다).

4. 일본어 감수자 경로(Q6).
