## 사용자에게 아직 확인받지 않은 메인의 결정

결정마다 지금 동작(메인이 정한 것)과 선택지를 적는다. 사용자가 답하면 해당 ADR 을 새로 쓰거나 고치고 이 목록에서 뺀다.

1. **순위 `lnmode` 필터의 뜻.** 지금은 "최고 기록이 그 LN 방식으로 친 판인 플레이어"만 남기고 그 안에서 순위를 센다(`chart_best` 키에 LN 방식이 없음). 선택지: (a) LN 방식별 최고 기록(키 확장 + 마이그레이션), (b) 파라미터 제거, (c) 지금대로. 문서 `docs/backend/api-spec.md` 4절, 테스트 부채 3.35.
2. **코스 램프의 서버 검사.** 0.1.0 클라이언트가 마지막 스테이지의 램프를 코스 램프로 보내므로 서버는 코스 램프를 판정 수와 대조하지 않는다(`course.service.ts` 의 `findCourseIntegrityFailure` 문서). 0.1.0 이 쓰이지 않게 되면 검사를 켤지. 테스트 부채 3.36.
3. **저장소에 남은 다른 사이트의 흔적(서빙하지 않음).** `web/data/tables/insane1/source.json`(원본 주소·HTTP 기록, 스냅샷 재현용), `web/scripts/snapshot-table.ts` 의 사용 예, `crates/rbms-config/src/tables.rs` 의 `same_as: ["darksabun.club/table/archive/insane1"]`(원본 주소를 이미 등록한 사용자에게 사본을 중복 등록하지 않기 위한 값)와 그 테스트, `docs` 의 조사 문서. 메인 판단: 기능에 쓰이는 `tables.rs` 는 유지, `source.json` 은 스냅샷 재현용으로 유지를 권한다. [표 페이지 ADR](2026-10-14-adr-table-page-no-source-notice.md) 의 현재 상태 절.
4. **기록 동기화의 거절 재전송 좁힘.** 저절로 시작한 동기화는 같은 빌드끼리 이미 거절된 판을 다시 보내지 않는다(수동과 빌드 변경 때는 보낸다). [거절 재전송 ADR](2026-10-15-adr-record-sync-refusal-resend.md).
5. **메뉴 입력의 PAD DEBOUNCE.** 컨트롤러 디바운스가 LR2 형이 되면서 메뉴에서도 뗌 뒤 2~16 ms 튀는 버튼이 두 번 눌린 것이 될 수 있다. 메뉴에만 옛 양방향 잠금을 둘지. [키보드 시각 ADR](2026-10-15-adr-keyboard-input-timing.md) 남은 한계 4, 테스트 부채 3.71.
6. **연습 판의 게이지 사망.** 지금은 게이지 잠금으로 구간 끝까지 판정한다(NONE 을 CONTINUE 로). 원본은 연습 패널로 돌아간다. A 원본대로 / B 지금대로 두고 ADR 로 남긴다. `reference-divergences.md` "연습과 #TOTAL" 절, `docs/play-options.md` 9절.
7. **기록 목표의 진행 중 값 여섯 질문(2026-10-19).** 지금 동작은 메인이 원본 의미로 정했다: 기준은 판정된 노트 수, 스킨 BEST 칸도 로컬 최고 판의 리플레이를 따름, RIVAL·다른 기기 IR BEST 는 비례, 비례로 물러날 때 화면 표시 없음, 같은 EX 가 여럿이면 처음 낸 판, 고스트가 늦으면 로딩이 기다림. 각 선택지는 [조사 문서](../reference/record-target-pace.md) 9절, [ADR](2026-10-19-adr-record-target-follows-its-run.md).
(8~12 는 2026-10-23 사용자가 추천안대로 확인했다: "1-11 추천대로". 8 은 결정이 바뀌어 "스킨 헤더의 확장 지원 표시가 있을 때만 재배정 키", 11 은 "코스 제출에 게이지 종류를 더해 등급을 채움"으로 정해졌고 [패널 키 opt-in](2026-10-23-adr-panel-keys-opt-in.md)·[코스 제출 게이지](2026-10-23-adr-course-submission-gauge.md) ADR 로 남겼다. 아래 "확인받은 것(2026-10-23)" 참고.)

**13. 코스 시작 게이지, 9슬롯 이월, LN 제약 (J-4·J-6·J-7).** 지금 동작(메인이 원본 규칙에 맞춰 정함): 코스 스테이지의 시작 게이지가 GAUGE 설정을 따르고(NORMAL 이하 CLASS, HARD EXCLASS, EX HARD 이상 EXHARDCLASS), 곡 사이에 아홉 게이지를 모두 이월하며, 코스의 `ln`·`cn`·`hcn` 제약을 플레이에 적용한다(CN·HCN 설정 사용자의 번들 코스가 LN 으로 돈다). 조사 추천안의 "R-BMS 가 이미 이 규칙을 가짐" 전제가 틀렸고 사용자는 "나머지도 추천대로" 만 말했다. 선택지: (a) 지금대로, (b) 시작 슬롯을 CLASS 고정으로 되돌림, (c) LN 제약은 보이기만 하고 LN MODE 설정대로 침. [ADR](2026-10-23-adr-course-stage-start-and-ln.md), 테스트 부채 3.103, QA 3.21 U16.

**14. 단위 인정의 게이지 모드 (J-11)와 조건 세부 (J-13).** 지금 동작: LR2·BEATORAJA·IIDX 어느 모드로 깼든 같은 단위를 주고 모드는 기록만 한다. `ranked` 판만, ASSIST·LIGHT ASSIST 램프 제외, 스테이지 정보가 없는 판(`v0.1.7` 이하, 0012 이전)은 소급하지 않는다. 설계서가 근거로 든 "결정 20 의 '모두 인정하되 기록'" 문구는 결정 요약에 없고 질문 원문이 저장소에 없어 메인 판단으로 적었다. 선택지: (a) 지금대로, (b) 모드 제한(예: LR2 만) 또는 모드별 단위, (c) 옛 판을 램프만으로 소급. [ADR](2026-10-23-adr-dan-auto-award.md), 테스트 부채 3.104, QA 3.21 U21.

**15. 레벨 폴더 제목의 표 기호 (J-14).** 지금 동작: 표 기호 + 레벨이라 발광 표의 `LV 12` 가 `★12` 가 되고 Stella 는 `st3`, Satellite 는 `sl5` 다(원본과 같다). 선택지: (a) 지금대로, (b) 발광만 `LV 12` 유지. [ADR](2026-10-23-adr-select-folder-stack.md), QA 3.21 U8.
