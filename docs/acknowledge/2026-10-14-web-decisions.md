## 2. 메인이 추천안으로 정한 것(되돌릴 수 있음)

사용자가 달리 정하면 그쪽을 따른다. 각 항목의 선택지와 근거는 괄호 안 문서의 "결정" 절에 있다.

| 번호 | 결정 지점 | 정한 것 |
| --- | --- | --- |
| M1 | 사본 주소와 색인 | 정본은 `https://bms.hyuns.uk/tables/insane1`(슬래시 없음. 운영이 끝 슬래시를 308 로 떼므로 `bmstable` 메타는 루트 상대 경로로 쓴다). 사본 페이지는 `noindex`(원본이 NOINDEX). 출처 표기와 삭제 요청을 받는다는 문구를 넣는다(insane-table). 대체됨(문구 부분): [2026-10-14-adr-table-page-no-source-notice.md](2026-10-14-adr-table-page-no-source-notice.md) |
| M2 | 표 자료의 원본 | DB 에 넣지 않고 스냅샷 파일을 직접 읽어 내고, 내 기록은 `chart.md5` 로 보강한다. 기존 `table_chart` 는 sha256 이 필수라 이 표(전 곡 md5 만)를 담지 못한다(insane-table, audit) |
| M3 | 폴더의 모델 | `user_folder`, `user_folder_item` 두 테이블. 곡 식별자는 md5 필수·sha256 선택. 한도는 폴더 50개, 폴더당 2,000곡, 전체 20,000곡, 이름 64자. 폴더 안의 묶음은 두지 않는다. `is_public` 컬럼은 만들어 두되 v1 의 동작은 사용자 결정(3절 Q3)을 따른다(user-folders) |
| M4 | 폴더의 통로 | 편집은 `/api/fe/me/folders…`(세션), 클라이언트 읽기는 `/api/players/{id}/folders` 와 `/api/players/{id}/folders/{folderId}`(본인만) 의 전용 통로. 선곡에는 뿌리에 `MY FOLDERS` 한 줄 → 폴더 → 곡. 로그아웃하면 저장본을 지운다. 가지고 있지 않은 곡은 폴더 줄의 (가진 곡/전체)로만 보인다(user-folders) |
| M5 | 기본 표를 넣는 방법 | 설정에 `seeded_default_tables` 표식을 두어 한 번만 넣고(지우면 다시 넣지 않는다, 같은 표의 원본 주소가 이미 있으면 건너뛴다), 저장소의 스냅샷을 실행 파일에 넣어 저장본까지 심는다. 오프라인 첫 실행에도 표가 보인다. 두 문서의 추천이 갈린 곳이며 user-folders 쪽을 택했다 |
| M6 | drizzle meta | `web/.gitignore` 에서 `/drizzle/meta` 를 빼고 journal 과 스냅샷을 되살려 커밋한다. 0000 의 `when` 은 운영에 적용된 값보다 작아야 다시 실행되지 않으므로 웹 작업 시작일(2026-09-09)보다 이른 2026-09-01 00:00 UTC 로 둔다(audit) |
| M7 | 화면 | 공개 화면(로그인·가입·가이드)도 같은 골격 안에 둔다. 기본 테마는 다크(토글로 라이트). 램프·난이도·판정 색은 기본 스킨 `theme.lua` 의 값. 사이트 이름은 R-BMS. Normal 클리어의 표시는 CLEAR. 설정은 사이드바 바닥의 계정 메뉴로. 폴더 편집은 명시 저장 + 미저장 경고. 곡 검색은 의존성 없이 입력 + 결과 목록. `docs/acknowledge/design.md` 와 달라지는 곳(design-direction 3.1.1 의 T1~T11)은 구현 웨이브가 그 문서에 반영한다 |
| M8 | 차트 메타 공백 | 표 스냅샷의 제목·아티스트로 표시를 보강하고, 클라이언트가 점수를 낼 때 차트의 제목·아티스트·레벨을 함께 올린다(계약은 클라이언트 연동 웨이브에서) |
| M9 | 리더보드 | `rank_points` 는 쓰는 코드가 없어 항상 0 이다. 산식을 새로 만들지 않고 실제 값(클리어한 차트 수, 그다음 플레이한 차트 수)으로 정렬한다 |
| M10 | Preview 배포 | 만들지 않는다. `web/vercel.json` 의 `ignoreCommand` 가 프로덕션이 아닌 빌드와 `web/` 이 바뀌지 않은 푸시를 건너뛴다. rate limit 저장소는 지금대로(인스턴스 로컬) 두고 뒤로 미룬다 |
| M11 | 비로그인 제출 | 서버의 `ALLOW_GUEST` 는 false 로 둔다. 로그인하지 않은 판은 로컬에만 저장된다 |
