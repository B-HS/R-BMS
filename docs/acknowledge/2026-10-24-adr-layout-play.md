## 배경

- 사용자 요청(2026-10-24): "리플레이를 볼때 해당 리플레이의 배치를 활용하여 나도 플레이하는 모드(battle모드였나? 그거랑비슷한거야)". 두 사람이 동시에 치는 배틀이 아니라, 남이(또는 예전의 내가) 친 판의 노트 배열을 그대로 가져와 새 판을 치는 기능이다.
- 조사 보고서 [2026-10-24-replay-pattern-play-survey.md](../reference/2026-10-24-replay-pattern-play-survey.md): 리플레이 본문은 RANDOM 옵션과 시드를 갖고, 배치는 `(차트, 옵션, 시드)` 로 결정적이다. 새 판의 배치 로드는 이미 `play_as_recorded`(리플레이대로)와 `retry_seed`(같은 배치 재시도) 경로를 갖는다.
- 서버 리플레이는 내려받을 때 CONVERGE 와 옵션 없음을 OFF 로 바꿔 들어온다(`ir_replay.rs:131-136`).

## 결정

### 1) 빌리는 것

- 리플레이의 **배치 옵션(RANDOM 계열)과 시드만** 빌린다. 게이지, SCRATCH AUTO, LN MODE, 판정 설정은 플레이어의 것을 그대로 쓴다(질문 3).
- 빌린 판은 일반 판과 같이 저장·전송한다. 표지 열이 없다(질문 5). 기록의 `random`·`seed`(점수 로그, 제출 본문, 저장 리플레이)는 빌린 값이다. 제출 본문 형식과 계약 골든은 바뀌지 않았다.
- 판이 도는 동안 `config.play.random` 만 빌린 값으로 바꾸고 플레이어의 값은 `own_play_options` 에 보관한다. 판 도중 설정이 저장돼도(`settings_to_save`) 플레이어의 값이 저장된다.
- 빌린 배치는 `load()` 에서 `play_as_recorded`·`retry_seed`·새 시드보다 먼저 쓴다. 리플레이를 들고 있으면(보는 중) 그 리플레이대로 배치하고 빌린 배치는 버린다.

### 2) 진입 길

| 길 | 어디서 | 키 |
| --- | --- | --- |
| 리플레이를 보는 중 | 보는 중인 리플레이의 배치로 그 판 자리에 새 판(`Transition::To(Loading)`) | 단축키 `ReplayPlayLayout`(기본 `J`, 키 설정에서 바꿈) |
| 선곡의 기록 모달 | 리플레이가 있는 기록에만 PLAY REPLAY 와 CLOSE 사이에 "PLAY THIS LAYOUT" 단추. 로컬 리플레이는 고스트도 붙는다 | `J`(키 설정의 같은 단축키), 마우스 |
| 선곡의 IR 랭킹 패널과 랭킹 모드 | 줄의 리플레이를 내려받아(`play_ranking_replay` 의 "배치만" 갈래) 받은 본문의 `chart.md5` 가 지금 차트와 같으면 빌린다 | `J`(패널에서), 컨트롤러는 이 단축키를 묶은 패드 버튼 |

- `Shortcut::ALL` 이 31 에서 32 로 늘었다(그룹 Replay, `config_key` `replay_play_layout`). 처음에 정한 `P` 는 다른 단위 소유 시험 두 개가 빈 키로 쓰고 있어 `J` 로 바꿨다. `J` 는 출하 레인 키, 역회전 키, 컨트롤 키 어디에도 쓰이지 않는다. 옛 키 파일에서 다른 Replay 키가 `J` 를 쓰면 새 단축키는 키 없이 남는다(시험 있음).
- 랭킹 모드의 흰 건반(리플레이 재생)과 겹치지 않는다: 레인에 묶인 키는 이 단축키가 아니라고 보는 가드가 있다. 파란 건반을 쥐고 REPLAY 를 누르는 길은 만들지 않았다(질문 2).
- 모달·패널의 힌트는 출하 키 `J` 로 고정 표기된다(`SelectModal` 에 필드를 더하지 않았다). 키를 옮기면 동작은 옮긴 키를 따르고 힌트의 `J` 는 틀려진다.

### 3) 거절(`LayoutRefusal`)과 알림

검사 순서: 코스·연습·`run_plays_itself`(오토플레이 중) 이면 `NotFreePlay` → 차트 md5(대소문자 무시)가 다르면 `ChartMismatch` → 라벨을 모르거나 CONVERGE 면 `UnsupportedOption` → 이 기기 기록이 아닌 리플레이가 OFF 로 빌려질 상황이면 `ArrangementUnknown`(서버가 CONVERGE·옵션 없음을 OFF 로 바꿔 보내므로 OFF 가 정말 OFF 인지 알 수 없다) → 시드 0 이고 OFF 가 아니면 `UnknownLayout`. OFF 는 허용, DP 는 허용. 거절은 화면을 그대로 두고 경고 알림(세 언어)만 낸다.

- 출하 기본값이 `PlayOptions::autoplay: true`(`crates/rbms-config/src/schema.rs:605`)라 AUTOPLAY 가 켜져 있으면 "손으로 친 판만 ..." 알림으로 거절된다.
- `--replay` 로 연 로컬 파일처럼 이 기기 기록이 없는 OFF 리플레이도 서버 리플레이와 구분할 수 없어 거절된다.
- 노트 위치가 LN 처리에 따라 달라지는 옵션(S-RANDOM, H-RANDOM, ALL-SCRATCH)을 정의 안 된 LN 이 있는 차트에서 빌리면, 요청에 LN MODE 필드가 없어 다른지 판별하지 못하므로 LN MODE 와 상관없이 경고만 낸다(거절하지 않는다).

### 4) 수명(질문 4)

같은 배치 재시도에서는 유지하고(파란 건반 + START, 점수가 갱신된 판의 R·7번 키, 실패 직후 SELECT 는 모두 `app_result::retry` 를 거치고 `retry_seed` 가 빌린 시드와 같을 때), 선곡·다음 곡·다른 배치·시드 없는 재시도(5번 키, 내장 결과 화면의 R)·결정 화면 이탈에서는 버리고 플레이어의 RANDOM 을 되돌린다. 넘겨받지 않은 `load` 나 md5 가 다른 `load` 도 쓰지 않고 버린다.

### 5) 고스트(M2, 보고서 질문 1)

- **로컬 리플레이에서 빌린 판에서만** 이번 판의 TARGET 이 그 리플레이의 페이스가 된다. `Borrowing.kept`(`KeptRun`: 기록의 `GhostSource` 와 EX)를 채우는 길은 보는 중 단축키(같은 md5 기록 가운데 리플레이의 seed·random·events 가 같은 기록을 찾는다)와 기록 모달이다.
- 이름은 `REPLAY <기록 시각>`, 최종 EX 는 그 기록의 값이다. 결과 화면도 같은 `run_target` 을 거치므로 값이 같다. 설정의 TARGET 행은 건드리지 않는다(한 판 한정).
- 재판정이 안 되면(FRAME 시계 리플레이, 노트 수·최종 EX 불일치) 기존 `rejudge` 가 콘솔에 이유를 남기고 비례 페이스로 물러난다.
- 서버 리플레이에서 빌린 판은 고스트 없이 TARGET 행을 따른다(서버 리플레이 고스트와 점수 행 배치 안 함: 질문 6, 서버 리플레이 판정 설정 S1 과 마이그레이션은 하지 않았다).

### 6) 배치 순열 골든

`crates/rbms-chart/src/shuffle.rs` 의 시험 모듈에 옵션 8개 x 7K·14K·9K 의 배치 24개를 시드 `0x001E_D5A7_C3B9_1F42` 로 고정했다. 순열 규칙이 바뀌면 이 시험이 실패한다.

## 이유

- 배치가 `(차트, 옵션, 시드)` 로 결정적이라 옵션과 시드만 빌리면 같은 노트 배열이 나온다. 게이지·LN MODE 까지 복사하면 점수·최고 기록 의미가 달라져 사용자 확인이 필요하다.
- 일반 판과 같이 저장하면 서버·로컬 스키마 변경과 마이그레이션이 없다. 사람이 친 판은 전부 저장·전송한다는 규칙과 맞는다.
- 로컬 리플레이만 고스트를 붙이는 이유: 서버 리플레이는 판정 설정을 몰라 재판정이 맞는지 보장할 수 없다.

## 기각된 대안

| 대안 | 기각 이유 |
| --- | --- |
| 게이지·SCRATCH AUTO·LN MODE 도 복사 | 점수 의미가 달라진다. 설정은 플레이어의 것 |
| 빌린 판에 표지 열 추가 | 로컬 DB 와 서버 마이그레이션이 필요(질문 5) |
| 선곡에서 파란 건반을 쥐고 REPLAY 키로 진입 | 랭킹 모드의 파란 건반 길게 누르기와 충돌 |
| 서버 리플레이 고스트(S1) | 서버 리플레이 판정 설정과 마이그레이션 0013, 계약 골든. 보류 |
| 시드 0 이거나 CONVERGE 를 OFF 로 빌림 | 배치가 달라진다. 거절하고 이유를 알린다 |
| 처음 정한 키 `P` | 다른 시험이 `P` 를 빈 키로 씀. `J` 로 변경 |
