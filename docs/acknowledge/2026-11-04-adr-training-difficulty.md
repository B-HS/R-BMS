# ADR — 훈련곡 난이도와 밀도 흐름 강화 (2026-11-04)

- 상태: 유효. 사용자 결정은 아래 "결정", 나머지는 메인 추천(사용자 확인 전)
- 설계: [plan/2026-11-04-training-difficulty.md](../plan/2026-11-04-training-difficulty.md) · 조사: [04 원인 진단](../reference/2026-11-04-ai-training-dashboard/04-training-difficulty-diagnosis.md), [05 실제 곡 밀도](../reference/2026-11-04-ai-training-dashboard/05-real-chart-density.md)
- 커밋: `efd431c`(한계 보간), `1256944`(범위·흐름·보정·LLM 역할), `555469e`(동시치기 채움·편한 밀도 자르기·생성기 3·프로필 3)

## 맥락

사용자(2026-11-04): "생성된 훈련곡이 너무쉬운데 그리고 실제 밀도처럼 나오지도않는듯하고말이야 AI 곡 생성부분을 조금 더강화해봐". 진단 결과, 기본 강도(push)의 집중 구간도 한계 L 을 넘을 수 없었고(범위 상한이 1.0 L), 구간 안 밀도가 완전히 평평했으며(2초 밀도 p50 = p90 = max), 종류별 배치가 목표를 최대 29% 깎고, 워밍업·쿨다운이 곡의 약 25% 였다.

## 결정

사용자(2026-11-04 답 "A / A / C"): 기본 강도는 L 의 100~110%, 최고 강도는 115~130%. "실제 밀도처럼 안 나온다" 는 체감이 낮은 것과 흐름이 단조로운 것 둘 다.

메인 추천:

1. 강도 범위는 곡 본문 2초 밀도(nps2)의 p90 에 건다. build `[0.90, 1.00] L`, push(기본) `[1.00, 1.10] L`, over(최고) `[1.15, 1.30] L`. 하한도 L 에 묶는다. 실제 곡에서 p90 이 범위 안이면 가장 진한 순간은 그보다 약 1.2배다.
2. LLM 은 종류·레인·의도·무게와 `level`(범위 안 위치), `shape`(흐름 원형)만 정하고, 수치는 서버가 계산한다.
3. 실제 곡 7,848곡에서 뽑은 1분 밀도 곡선 원형 4개(평탄·점증·중반 골·앞 높음-골)에 시드 잡음과 짧은 봉우리를 더해 구간 안에서도 밀도가 오르내린다.
4. 쿨다운을 없애고 워밍업은 곡 길이의 8% 이하. 종류별 손실 보정(실제/목표 0.97~1.04).
5. 단타 상한을 넘는 목표는 먼저 기준 BPM 을 220 까지 올리고, 그래도 모자라는 몫은 2~3노트 동시치기로 채운다(실제 곡도 고점에서 동시치기가 늘어난다). 채운 구간은 보정 목록에 남고 상세에 행/초를 함께 보인다.
6. 프로필의 밀도 한계는 맞춤 곡선이 기준선을 지나는 점의 보간(±1 NPS 계단 오차 제거), 편한 밀도는 한계 아래로 자른다. 프로필 버전 3, 생성기 버전 3, 프롬프트 버전 2.

## 결과(측정, 6,480곡 합성)

- 본문 nps2 p90/L 평균: push 1.00~1.09, over 1.14~1.27. 한계 24 사용자의 push·over 99.4% 가 범위 안.
- 평평한 곡(max/p50 < 1.25) 1.34%. 종류별 실제/목표 0.97~1.04.
- 남은 것: push `level` 0 에서 곡 평균이 L 의 0.70 아래인 곡(설계식의 경계값), LN 종류·3동시 연타의 고밀도 평평함. [테스트 부채](../quality-assurance/2026-10-14-test-debt.md) 3.160~3.161.

## 영향

이미 만든 훈련곡은 저장된 바이트 그대로다. 새로 만들면 새 방식이 적용된다. 프로필은 다음 읽기에서 한 번씩 다시 계산된다(운영 DB 변경 없음).
