# 사용자 확정 결정 (rbms 포팅)

## 대상
beatoraja core PLAY 모듈의 Rust 재구현(rbms). 스킨/IR/셀렉트는 범위 밖.

## 결정 (2026-05-31 합의)
1. **그래픽 스택**: wgpu + winit. 렌더러는 trait 추상화로 교체 가능.
2. **첫 마일스톤 범위**: 입력 + 판정까지 한 번에.
3. **첫 타깃 키 모드**: 7K + 스크래치(8레인).
4. **확장성(필수)**: PMS·5K·14K 등 추가가 쉬워야 함 → 모드는 **데이터 주도 ModeProfile**(레인 레이아웃/채널 매핑/입력 바인딩/판정 프로파일/게이지)로 분리. 코어 엔진은 모드 불문 공통.
5. **테스트 데이터**: 사용자 BMS 라이브러리 경로(엔드투엔드) + 저장소 내 최소 합성 픽스처(단위 테스트). **경로 입수 대기.**

## 결정 보류/미정
- 오디오 스택은 도메인상 자명하여 cpal + symphonia + 커스텀 샘플정확 믹서로 진행(클럭=샘플수). 이의 시 변경.
- 크레이트 정확 버전: 기반 조사 워크플로우 산출 후 Cargo.toml 확정.
- 워크스페이스 vs 단일 크레이트: 아키텍처 산출 후 확정(첫 모듈은 단일 크레이트+모듈 유력).
