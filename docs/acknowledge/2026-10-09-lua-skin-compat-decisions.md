## 메인이 정한 기본값 (사용자에게 고지, 이의 없음)

사양 §2 의 E1~E10 이 원문이다. 요지: Lua 격리와 쓰기 오버레이(E1), R-BMS 고유 화면·오버레이 유지(E2), 기존 단축키 + START/SELECT 신설(E3), 내장 화면 폴백 유지(E4), 누락 글리프는 앱 폰트로(E5), 기본 창 1280x720 + 해상도 설정(E6), 그리기는 레퍼런스 HEAD 그대로·입력 결함은 원작 의도로(E7), IR 상태는 실제 값 공급·목록 연결은 후속(E8), 기본 스킨에 9키 포함(E9), 색 공간은 웨이브 1 비교 뒤 확정(E10).

## 기각한 대안

| 대안 | 기각 이유 |
| --- | --- |
| ModernChic 개변판을 저장소에 포함 | D1. 원작자 표기 조건과 제3자 자산(음성, 캐릭터 그림, 일부 랭크 그림, 출처 불명 동영상) 정리가 필요하다 |
| 풀 Lua 스킨을 정적 JSON 으로 변환해 읽기 | 본체가 로드 시 곡 상태(`main_state.option`)로 구조를 분기하고 함수 값을 매 프레임 부른다. "수정 없이 읽기"와 양립하지 않는다 |
| Lua 5.4 유지 + 경계 보정 | 수 체계가 달라 문자열화(`5.0`)와 꺼진 타이머 산술이 스킨 내부에서 어긋난다. `lua52` 피처가 이미 있다 |
| 새 스킨 모델 작성 | 기존 `SkinDef` 가 레퍼런스 모델과 일치한다 |
| 혼합 합성 유지 | D3. 사용자가 부적합으로 판정 |
| 내장 play/select/result 화면 삭제 | 24키와 스킨 로드 실패의 폴백이 필요하다(E4) |
