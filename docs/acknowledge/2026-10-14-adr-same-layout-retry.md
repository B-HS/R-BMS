# ADR: 결과 화면의 파란 건반 + START 는 같은 배치로 다시 하기

> 최종 갱신 2026-10-14 · 대응 커밋 7095ef7
> 상태: 유효 · 결정일 2026-10-14 · 결정자 사용자(요청) + 메인(세부)

## 배경

사용자 요청: 곡이 끝난 뒤 파란 건반(2, 4, 6키)을 누른 채 START 를 누르면 똑같은 랜덤 배치로 다시 시작하게. 결과 화면에는 이미 원본 키 표의 일곱째 건반(그리고 R 키)으로 "그 배치 그대로 다시"가 있었으나 사용자가 말한 조합은 없었다.

## 결정

1. 결과 화면에서 파란 건반 가운데 하나를 누른 채 START 를 누르면 같은 시드와 같은 옵션으로 그 차트를 다시 한다. 어느 판이든(어시스트 여부와 상관없이) 같다.
2. 파란 건반: 7키 모드는 둘째·넷째·여섯째(`BEAT_BLUE_KEYS = [1, 3, 5]`), 5키 모드는 둘째·넷째(`FIVE_BLUE_KEYS = [1, 3]`), 9키(팝픈)는 넷째·여섯째(`POPN_BLUE_KEYS = [3, 5]`). 양쪽 사이드 모두.
3. 원본 키 표에서 확인(결과 화면 나가기)을 맡는 파란 건반은 눌렀을 때가 아니라 뗄 때 확인한다. 그래야 그 건반을 누른 채 START 를 누를 수 있다. 혼자 누르고 떼면 전처럼 선곡으로 나간다.
4. 내장 결과 화면도 같은 조합을 읽는다.
5. 다시 하기가 넘겨받는 시드(`retry_seed`)는 기록된 그대로 쓴다([2026-10-14-adr-layout-seed-range.md](2026-10-14-adr-layout-seed-range.md)).

## 이유

사용자 요청 원문. 같은 배치 연습은 RANDOM 판에서 의미가 크고, IIDX 의 조작 습관(파란 건반 + START)에 맞춘다. 확인 키를 뗄 때로 옮긴 것은 조합을 가능하게 하는 가장 작은 변경이다.

## 기각된 대안

기록된 대안 없음(사용자 요청을 그대로 구현).
