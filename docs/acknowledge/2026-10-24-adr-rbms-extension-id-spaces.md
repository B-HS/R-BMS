# ADR: R-BMS 확장 id 를 정수·Float·Rate·텍스트·참조 이미지 공간으로 넓히고 다섯 기능에 번호 배정

> 최종 갱신 2026-10-24 · 대응 커밋 66b9e63
> 상태: 유효 · 결정일 2026-10-24 · 결정자 메인(통합 결정 M7)과 사용자(선곡 UI 질문 4 "정수·실수·문자열도 21000~21199 숫자 범위", NOTES RADAR 질문 5 "외부 스킨 노출", 둘 다 2026-10-24 "18번까지 전부 추천안대로") · 커밋 `72726c7`(공간 개방·상수·라우트), `54ff02c`(참조 이미지 칠하기), `423484b`(랭킹 id), `d75b819`·`b5f15df`(분석·선곡 보조·언어 id), `eadde84`(확장 불린 `op` 로더 수리)
> 부분 변경하는 결정: [2026-10-22 확장 id ADR](2026-10-22-adr-rbms-extension-ids.md)(그 파일의 문장은 고치지 않았고 상태 줄과 색인만 표시했다). 바뀌는 문장: "정수·Float·Rate·텍스트·참조 이미지에는 확장이 없다", "21002~21099 미사용", "원본 선언을 확인하는 문을 고치지 않았다", "`op` 에는 쓰지 못한다". 옛 사설 id 20001~20316 은 되살리지 않는다.

## 배경

- 2026-10-22 ADR 은 이벤트 21000~21099 와 불린 21100~21199 두 대역만 열었다. 정수(`number`)·실수(`float_number`)·비율(Rate)·텍스트·참조 이미지는 원본이 선언한 id 에만 답했다. 원본에 없는 id 에 Lua `main_state.number` 는 0 을, 이미지 세트의 `value` 는 `ref` 로의 되돌림을, 텍스트 `ref` 는 "속성 없음"을 줬다(`crates/rbms-skin/src/lua/main_state.rs` 두 함수, `skin_render/draw.rs`, `skin_render/text.rs`, `songlist/build.rs` 의 다섯 문).
- 2026-10-24 다섯 기능은 원본에 id 가 없는 값을 스킨에 줘야 한다: 레인별 노트 수, NOTES RADAR 여섯 축과 육각형 그림, 형제 난이도 레벨, 폴더 램프 분포, 내 기록 6줄(숫자와 날짜 글자), UI 언어, 랭킹 모드 켜짐과 열기 이벤트. 조사 보고서 네 개가 서로 다른 번호를 제안했고 둘이 겹쳤다(이벤트 21002 를 랭킹과 리플레이가 함께, 레이더 Float 와 rate 의 21020~21025).
- 조사 중 확인한 함정: Lua `float_number(id)` 와 호스트 `float()` 는 Float 공간에서 못 찾으면 Rate 공간으로 다시 묻는다(`skin_host/mod.rs:975-977`). 두 공간에 같은 번호를 주면 한쪽이 가려진다.

## 결정

### 1) 공간과 대역

모든 새 id 는 21000~21199 안이다(범위 밖 배정 금지). 이벤트는 21000~21099, 불린은 21100~21199, 정수·Float·Rate·텍스트·참조 이미지는 21000~21199 를 각자의 공간에서 쓴다. 이미지 인덱스 공간에는 대역이 없다(R-BMS 의 것을 고르는 이미지 인덱스가 없다).

- 공간끼리는 번호가 겹쳐도 된다. 단 **Float 와 Rate 는 한 공간처럼 다룬다**: 같은 번호를 두 공간에 주지 않는다(시험이 지킨다).
- 새 id 의 상수는 한 단위가 한 번에 만들고(K0), 다른 단위는 읽기만 했다. 필요한 id 가 없으면 만들지 않고 멈추는 규칙으로 W1~W5 를 진행했고 중간에 번호를 더하지 않았다.
- 아직 값을 답하지 않는 id 는 그 종류의 부재 값(`INTEGER_ABSENT`, `FLOAT_ABSENT`, `TEXT_ABSENT`, 불린 거짓, 이벤트 무시)을 낸다. 기본 스킨은 부재 값이면 그리지 않는다.

### 2) 문 다섯 곳을 하나의 질문으로

`crates/rbms-skin/src/property/extension.rs`(새)의 `implements(space, id)` 가 "원본이 구현한 id 이거나 그 공간의 확장 대역 안"이다. `reference_implements`(원본이 말하는 것)와 생성된 원본 id 표는 바꾸지 않았다.

| 문 | 위치 | 전 | 후 |
| --- | --- | --- | --- |
| Lua `main_state.number` | `lua/main_state.rs` | 원본 id 가 아니면 0 | 대역 안이면 호스트에 묻는다(값이 없으면 `INTEGER_ABSENT`) |
| Lua `main_state.float_number` | 같은 파일 | 원본 id 가 아니면 0 | Float 나 Rate 대역 안이면 호스트에 묻는다(없으면 `FLOAT_ABSENT`) |
| 이미지 세트의 `value` 가 정수 id 일 때 | `skin_render/draw.rs` | 원본 id 가 아니면 `ref` 로 되돌림 | 대역 안이면 호스트의 값으로 고르고, 값이 없으면 `ref` 로 돌아가지 않고 숨김 |
| 텍스트 `ref` | `skin_render/text.rs` | 원본 id 가 아니면 속성 없음 | 대역 안이면 호스트에 묻는다 |
| 선곡 목록 막대의 숫자 칸이 읽는 정수 id | `songlist/build.rs` | 원본 id 만 자기 값으로 읽음 | 대역 안도 자기 값으로 읽음 |

- 불린: 로더가 `op = { id }` 의 정수를 원본이 선언한 id 로만 인정해 확장 불린을 스킨 자체 옵션으로 분류하고 그 객체를 지웠다(`crates/rbms-skin/src/loader/track.rs` `is_builtin_option`). D1·D2 가 처음 이 함정을 만나 `draw` 함수로 우회했고, I7 이 `is_builtin_option` 을 `extension::implements(Boolean, id)` 로 고쳐 확장 불린(21100~21199, 음수 포함)을 `op` 에 직접 쓸 수 있게 했다(`eadde84`). 2026-10-22 ADR 의 "`op` 에는 쓰지 못한다"는 이 결정으로 더는 맞지 않는다. 함수 필드(`draw`, `value`, `text`)에서 `main_state.option` 으로 읽는 길도 그대로 된다.
- 확장 이벤트는 원래 문이 없다(`reference_implements(Event, _)` 가 항상 참). 라우트만 더했다.

### 4) 값이 생기는 때

- Chart 클러스터(레인·레이더·350~353·92·그래프)는 선곡에서 커서가 150 ms 머문 뒤에 생긴다. 레이더는 곡 DB 에 현재 버전 행이 있으면 즉시, 레인·그래프는 작업자 스레드 파싱이 끝난 뒤다. 커서가 움직이는 중, 폴더·코스 막대, 코스 탭에서는 부재다.
- Select 클러스터 값은 프레임의 `draw` 에서 갱신한다(커서·목록·기록 수가 바뀔 때).
- 언어 불린은 모든 화면의 System 클러스터가 답한다. 헤더 읽기 단계에서는 `main_state` 가 비어 읽을 수 없고(영어로 본다) 함수 필드나 `op` 로만 쓴다.

## 이유

- 값 읽기가 원본 id 로 가능한 것은 원본 id 를 쓰고(순위 슬롯, 선곡 350~353), 원본에 없는 값만 확장 대역에 둔다. 외부 스킨이 이미 굽고 있는 라벨과 어긋나는 재사용을 피한다.
- 문 다섯 곳을 하나의 `implements` 로 모아 "확장 id 는 원본 id 와 같은 규칙으로 답한다"를 한 곳에서 지킨다. `reference_implements` 를 고치면 "원본이 구현하는 id 수" 시험이 거짓이 되므로 그 의미는 두었다.
- Float 와 Rate 를 한 공간처럼 다뤄 호스트 되돌림 때문에 생기는 가림을 번호 단계에서 막았다. 레이더는 Float, 레인 막대 비율과 램프 비율은 Rate 에만 준다.
- 숫자 범위를 21000~21199 하나로 모아 외부 스킨과 겹칠 가능성이 있는 위치를 한 대역으로 알린다.

## 기각된 대안

| 대안 | 기각 이유 |
| --- | --- |
| 조사 보고서가 제안한 번호(레이더 float·정수 21150~21155, 참조 이미지 21160, 리플레이 이벤트 21002~21005, 레이더 Rate 21020~21025) | 서로 겹친다. 이 표로 통일(메인 통합 결정 M7) |
| 정수·실수·텍스트를 대역 없이 원본 id 재사용 | 외부 스킨의 라벨과 어긋난다 |
| Float 와 Rate 를 같은 번호로 따로 둠 | Lua 와 호스트가 두 공간을 함께 읽어 한쪽이 가려진다 |

| 확장 불린은 `op` 에 쓰지 못한다는 규칙 유지 | 기본 스킨 객체가 지워지는 함정이라 로더를 고쳤다(2026-10-24) |

## 영향과 관련 파일

- 외부 스킨: 확장 대역의 정수·텍스트 id 를 자기 용도로 쓰던 스킨은 이제 0 이 아니라 부재 값(`INTEGER_ABSENT`)을 받고 이미지 세트의 `value` 도 `ref` 로 돌아가지 않고 숨겨진다. 선곡에서 원본 id 350~353·92·`judgegraph`·`bpmgraph`·순위 슬롯이 값을 내는 것은 원본과 같아지는 변화이고 "지금 R-BMS 대비 바뀜"이다(외부 스킨이 보이는 것이 달라진다).
- 코드: `crates/rbms-skin/src/property/extension.rs`, `crates/rbms-skin/src/lua/main_state.rs`, `crates/rbms-skin/src/loader/track.rs`, `crates/rbms-render/src/skin_render/{draw,text,refs,songlist/build}.rs`, `apps/rbms-player/src/skin_host/{extension,mod,chart,select,select/browse,system,ir}.rs`, `assets/skins/rbms-default/lua/props.lua`(`props.extension` 과 `extension_event`·`extension_number`·`extension_float`·`extension_rate`·`extension_text`·`extension_image`).
- 시험: `skin_host/tests.rs` 의 라우트 시험(`NOT_YET_FILLED` 는 모든 묶음이 채워져 비었다), `property/extension.rs` 의 대역 시험, `loader/track.rs` 의 `op` 시험 3개, `skin_host/select/tests.rs` 의 "라우트된 모든 Select 확장 id 가 답한다".
- 문서: [skin.md](../skin.md) 1.4절 표, [play-options.md](../play-options.md).
- 남은 위험: 기본 스킨의 선곡 문서는 확장 불린을 `op` 로 쓰는데 선곡 상태(`shown`)가 비어 있는 첫 프레임에는 음수 확장 `op` 가 거짓으로 답한다(이전 함수 방식은 그때 참이었다).
