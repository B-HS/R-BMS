# Phase G 배선 지시 색인

W2 병렬 갈래는 자기 소유 파일 밖을 고치지 않는다. 호출부 변경이 필요하면 이 디렉터리에
갈래별 파일로 **정확한 패치 지시**를 남기고, W3 의 통합 갈래(G8)가 그 지시만 보고 배선한다.

## 지시 파일 형식

한 항목 = 한 패치. 아래 네 가지를 빠짐없이 적는다.

1. **파일** — 레포 루트 기준 경로
2. **위치** — 함수명·심볼명 앵커(줄 번호 금지, 통합 시점에 이미 어긋난다)
3. **코드** — 삽입·교체할 정확한 코드 블록
4. **근거** — 스펙 절 번호, 그리고 이 변경 없이 무엇이 깨지는지

## 갈래별 파일

| 파일 | 갈래 | 주제 |
|---|---|---|
| `g1.md` | 곡DB | 스캔 진입점 교체, `is_chart` 확장자, 곡선택 목록의 데이터 소스 |
| `g2.md` | 스코어DB | `ScoreBook` → `ScoreDb` 교체, 결과 기록 경로, 리플레이 GC 호출 |
| `g3.md` | 코스 | `Stage`/`StageId` 확장, COURSE 탭, 코스 결과 화면, 코스 IR 제출 |
| `g4.md` | 연습 | 연습 진입 키, 게이지 락, `ir_submission_block_reason` 의 practice 사유 |
| `g5.md` | 컨트롤러 | 프레임 입력 루프의 패드 폴링, 키 컨피그 PAD 열 |
| `g6.md` | 시스템 사운드 | 사운드 세트 로드, 화면별 재생 계기, 설정 행 |
| `g7.md` | 멀티 IR | 프로필 축 주입, 설정 행, 랭킹 패널의 프로필 탭 |
| `g9.md` | bmson | `rbms_parser::parse` 디스패치, 스캔 확장자 필터 |

지시가 없는 갈래는 해당 파일을 만들지 않는다. G8 은 존재하는 파일만 읽는다.
