# Phase H 수동 확인 절차

## 범위와 준비

자동 검사는 오디오 장치 출력, 실제 BGA, 실제 코스 진행, 외부 IR 응답을 확인할 수 없다. 이 절차는 `README.md`의 실행 명령으로 실제 출력 장치가 연결된 환경에서 수행한다. 연습 확인에는 LN과 BGA 이벤트가 있는 차트, 코스 확인에는 해석 가능한 2스테이지 이상 코스, IR 확인에는 로그인한 primary와 추가 enabled 프로필 및 랭킹·리플레이를 제공하는 서버가 필요하다. 계정·토큰·키 값은 문서나 로그에 기록하지 않는다.

## AUDIO

1. 곡선택에서 프리뷰가 있는 곡과 없는 곡을 번갈아 포커스한 뒤, interactive 단일 차트를 시작해 여러 레인 키를 누른다.
2. 차트 시작 직후 BGM의 첫 소리와 키음을 듣고, 곡선택으로 돌아와 프리뷰 전환을 여러 번 반복한다.

합격 기준: 입력 키음이 눈에 띄는 지연 없이 들리고, BGM 시작이 차트 시작과 맞으며, 프리뷰 전환과 재생 중에 클릭·팝·끊김이 없다.

## Practice

1. LN의 시작 또는 끝이 범위 경계를 넘고 범위 안에 BGA 변화가 있는 곡을 선택해 `F4`를 누른다.
2. START TIME과 END TIME을 경계 양쪽으로 설정하고 `Enter`로 시작한다. 종료 뒤 같은 설정으로 한 번 더 반복한다.

합격 기준: 경계를 가로지르는 LN의 시작·종료 판정이 유지되고, 범위 안 BGA가 표시되며, 반복 실행에서 설정·BGA가 누적되거나 사라지지 않는다. 연습 결과는 로컬 기록과 IR 제출에 반영되지 않는다.

## Course

1. `Shift+Tab`으로 COURSE 탭을 열고, 2스테이지 이상이며 모든 차트를 찾은 코스를 `Enter`로 시작한다.
2. 첫 스테이지를 비최대 게이지와 유의미한 콤보로 끝낸 뒤, 둘째 스테이지 시작 상태와 최종 COURSE RESULT를 확인한다.

합격 기준: 둘째 스테이지의 초기 게이지·콤보가 첫 스테이지 종료 상태에서 이어지고, COURSE RESULT의 게이지·점수·콤보 집계가 실제 최종 진행과 일치한다.

## Multi-IR

1. SETTINGS의 NETWORK에서 primary와 추가 enabled 프로필을 준비하고 곡선택으로 돌아온다.
2. `I`로 IR RANKING 패널을 열고 `Q`와 `E`로 primary를 전환한다. 각 전환 뒤 랭킹이 새 primary 기준으로 다시 표시되는지 확인한다.
3. 리플레이가 있는 랭킹 행을 선택한 뒤 재생을 시작한다.

합격 기준: 프로필 라벨과 랭킹이 같은 primary를 가리키고, 이전 서버의 늦은 응답이 새 랭킹을 덮어쓰지 않으며, 리플레이 다운로드·재생이 선택한 primary 서버를 사용한다. 추가 프로필만 설정한 경우에도 점수 fan-out 완료 상태가 수렴한다.
