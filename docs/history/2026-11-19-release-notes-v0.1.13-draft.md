## R-BMS v0.1.13

v0.1.11 이후의 변경입니다(v0.1.12 는 게시하지 않았습니다).

### 블루투스 이어폰·헤드폰 (macOS)
- 출력 장치가 스스로 알리는 지연만큼 곡 시계를 늦춰, 노트와 판정이 **들리는 소리**에 맞습니다. AirPods Pro 2 는 약 160 ms 를 알립니다. SETTINGS > AUDIO 의 **OUTPUT LATENCY**(AUTO 기본 / OFF)로 끕니다.
- 보정이 30 ms 이상이면 장치 이름과 함께 한 번 알립니다. 그 장치에 맞추려고 JUDGE OFFSET 을 옮겨 두셨다면 되돌려 주세요(이중 보정이 됩니다).
- 출력 장치를 "시스템 기본"으로 두면 판을 시작할 때마다 지금의 기본 장치를 다시 확인합니다. 앱을 켠 뒤 이어폰을 연결해도 다음 판부터 맞습니다.
- 앱이 macOS **Game Mode** 대상이 됩니다. WINDOW MODE 를 BORDERLESS(macOS 전체 화면)로 두면 OS 가 AirPods 지연과 컨트롤러 입력 지연을 줄입니다(Apple silicon, macOS 14 이상. 켜질지는 OS 가 정합니다).
- 못 하는 것: 키를 누른 뒤 나는 키음은 블루투스 구간만큼 늦게 들립니다. 소프트웨어로 없앨 수 없습니다.

### 화면
- **WINDOW MODE** 에 FULLSCREEN(독점 전체 화면)이 생겼습니다. RESOLUTION 에 가장 가까운 모니터 모드를 가장 높은 주사율로 씁니다. 얻지 못하면 BORDERLESS 로 열고 알립니다.
- **플레이 화면**에 세 가지가 보입니다. 곡 머리 오른쪽에 곡을 고른 폴더(예: `発狂BMS / ★8`), 필드 아래에 그 판의 게이지·배치·어시스트 옵션, 판정 위 줄 오른쪽에 현재 NPS(직전 1초의 노트 수). NPS 는 스킨 메뉴의 `NPS Display` 로 끕니다.
- **선곡 화면**을 정돈했습니다. 머리를 한 띠로 묶고 폴더 경로를 머리로 올렸으며, 곡 제목 글자를 줄이고 LEVEL·BPM 을 제목 옆에 붙였습니다. 바닥 안내는 한 줄입니다.
- **클리어 램프**: SCRATCH AUTO 로 깬 곡은 끝난 게이지에 따라 목록 램프 색이 다릅니다(ASSIST EASY·CLEAR·HARD·EXHARD). 어시스트 없이 깬 램프와 SCRATCH AUTO 로 깬 기록이 함께 있는 곡은 램프가 위아래로 나뉘어 둘 다 보입니다(위는 어시스트 없는 램프, 아래는 어시스트 등급). 이미 쳐 둔 기록에도 적용됩니다.
- **판정 위치가 해상도마다 달라지던 문제**를 고쳤습니다. JUDGE POSITION 같은 스킨 메뉴의 위치·크기 값을 화면 화소가 아니라 스킨 좌표(1920x1080 기준)로 읽습니다. 1920x1080 이 아닌 화면에서 맞춰 둔 값은 한 번 다시 맞춰 주세요.

### 키 설정
- 조작 목록에 **ESC** 가 생겼습니다. 컨트롤러 버튼이나 보조 키에 줄 수 있고, 모든 화면에서 Esc 키와 같게 동작합니다(플레이 중 HOLD·DOUBLE TAP 포함).
- 조작과 단축키에 **키 2개 조합**을 줄 수 있습니다(키보드·컨트롤러). 키 편집기에서 첫 키를 누른 채 둘째 키를 누르면 조합, 한 키를 눌렀다 떼면 단일 키입니다. 예: START + SELECT 를 ESC 로. 레인 키는 단일 키만 됩니다.
- 레인 키와 같은 키에 묶인 조작은 그 모드에서 듣지 않고 레인이 칩니다(전에는 일부 조작이 레인을 막았습니다).

### LAYOUT PICK 과 배치 저장
- LAYOUT PICK 의 미리보기가 내 HI-SPEED·커버 설정으로 실제 속도로 흐릅니다. Space 재생·정지, Page Up/Down 네 마디, Home 처음으로. 소리는 나지 않습니다.
- 결과 화면에서 **P** 를 누르면 그 판의 배치를 저장합니다(RANDOM·R-RANDOM·MIRROR 같은 레인 단위 배치). LAYOUT PICK 오른쪽의 CAPTURED 목록에서 골라 같은 배치로 바로 칠 수 있습니다. 목록은 오른쪽 화살표로 들어가고 Tab 으로 이 곡·전체를 바꾸며 Delete 두 번으로 지웁니다.

### 고친 것
- 빌린 배치(LAYOUT PICK·리플레이 배치)로 치던 판을 새 배치로 재시도하면 그 판이 내 배치 옵션으로 기록되던 문제. 이전 버전에서 이렇게 기록된 판은 그대로입니다.
- 차트 맨 앞의 소리(시작과 동시에 나오는 긴 BGM 포함)가 판마다 최대 약 30 ms 늦게 시작하던 문제. 대신 판 시작 직후의 정지가 약 40 ms 길어집니다.
- 연습 화면에서 오디오 설정 변경이 뒤늦게 적용되며 키음이 사라질 수 있던 문제.

### 알려진 것
- 출력 지연 자동 보정은 macOS 만 됩니다. Windows 는 JUDGE OFFSET 으로 맞춰 주세요.
- 새 화면 문구의 한국어·일본어는 초안이라 어색한 곳이 있을 수 있습니다.
- Windows 는 아직 코드 서명이 없어 처음 실행할 때 SmartScreen 이 한 번 묻습니다.

### 설치
- macOS(Apple silicon·Intel): `R-BMS-macos-universal.dmg` 를 열어 R-BMS 를 응용 프로그램으로 끌어 놓습니다. 서명·공증판입니다.
- Windows: `rbms-windows-x64.zip` 을 풀고 `rbms-player.exe` 를 실행합니다.
- 각 파일의 SHA-256 은 함께 올린 `.sha256` 파일에 있습니다.
