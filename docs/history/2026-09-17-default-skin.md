# 기본 스킨 고도화 1차 결과 (2026-09-17)

이 이력의 완료는 기본 장식·배치·설치와 기존 기능 보존에 한정한다. 모든 화면 요소를 스킨 파일로 교체하는 전체 고도화는 완료되지 않았으며, 남은 기능과 순서는 `docs/plan/2026-09-17-default-skin.md`에 구분해 기록했다.

## 구현

- 외부 자료의 화면 구조를 분석하고 독립 그래픽과 설정 파일을 `assets/skins/steel-neon/`에 제작했다. 원본 이미지·영상·음성·글꼴은 저장소에 포함하지 않았다.
- JSON5 `composition: 'overlay'`로 선택·플레이·결과의 기존 동적 콘텐츠와 클릭 영역을 유지하면서 장식을 합성한다. 생략 또는 `replace`는 기존 교체 동작이다.
- 곡 선택의 목록·상세·커버·행 간격을 `theme.ron`으로 조정한다. 새 프리셋은 오른쪽 목록과 왼쪽 상세를 쓰고, 기존 테마의 누락 필드는 이전 좌표로 해석한다. 테마의 잘못된 좌표·행 크기는 안전한 기본값으로 되돌린다.
- 단일 필드의 왼쪽 노트 영역·중앙 BGA·오른쪽 목표 그래프는 `play.ron`, 이중 필드의 배치는 `play-dual.ron`에서 조정한다. 장식 이미지도 두 배치에 맞춰 분리했다.
- 첫 실행 또는 적용 표시가 없는 기존 설정에서는 8개 지원 화면의 비어 있는 문서 선택만 새 기본값으로 연결한다. 기존 명시적 문서·편집 파일은 덮어쓰지 않는다. 24K 파일은 설치하되 아직 선택하지 않는다. 읽을 수 없는 설정 파일은 이 자동 적용 과정에서 저장하지 않는다.
- 색과 이미지는 `palette.json`, `tools/generate-assets.py`, PNG 파일로 편집할 수 있다. JSON5는 설정 화면의 다시 읽기, RON은 앱 재시작으로 반영된다.

## 검증

- 문서 로더 54개, 문서 모델 22개, 렌더러 문서 테스트 20개 통과.
- 선택 화면 95개, HUD 10개, 기본 설치 2개, 기존 선택 보존 1개, 기본 문서 8개 컴파일·경고 0건 검사 1개, 합성 화면 7개 통과.
- 생성 스크립트 실행 성공. 결과 PNG 6개를 생성했고 실제 이미지 디코드와 크기를 확인했다.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --all-features -- -D warnings`, `git diff --check` 통과.
- 저장소 파일에서 금지된 외부 고유 명칭 검색 결과 0건.

## 남은 확인

- 실제 GPU 화면과 오디오 동반 플레이는 이 작업에서 실행하지 않았다. 화면 배치는 CPU 렌더 테스트와 생성 이미지로 확인했다.
- 현 범용 문서 렌더러는 노트·곡 목록 등의 객체를 완전히 교체하지 않는다. 기본 스킨은 합성 모드로 기존 기능을 보존한다.
