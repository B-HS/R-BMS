# 2026-05-31 — M2 오디오 엔진

## 한 일 (rbms-audio)
- deps(검증): cpal 0.17.3, symphonia **0.5.5**(0.6은 API 대개편이라 안정판 핀), rtrb 0.3.4. (rubato는 M2 미사용 — voice stride 리샘플로 대체, 추후 고품질 오프라인 리샘플용으로 재도입 검토.)
- `decode.rs`: symphonia로 WAV/OGG/FLAC/MP3 → interleaved f32(네이티브 레이트). probe→format→decoder 루프, `SampleBuffer::copy_interleaved_ref`.
- `mixer.rs`(순수, RT-safe): `SampleData`(네이티브 레이트), voice pool, **fractional stride로 인-보이스 리샘플(레이트변환+피치 동시) + 선형보간**, equal-power pan, 같은 key retrigger cutoff, `at_frame` 샘플정확 delay, `SAMPLES_PLAYED` 클럭. 콜백 무할당·무락.
- `engine.rs`: cpal 출력 스트림(F32/I16/U16), rtrb 명령큐, `AtomicU64` 클럭, 키음 bank. **마스터 클럭 = 재생 샘플 / rate**(vsync 아님 — beatoraja 타이밍 개선의 토대). 디코드 버퍼는 bank가 보유해 RT 스레드에서 dealloc 안 됨.

## 설계 메모
- 리샘플을 로드시 일괄(rubato)이 아니라 voice stride로 미룸 → 코드 단순·RT-safe·피치 동시 처리. 품질은 선형보간(키음에 충분, beatoraja도 per-sample 보간). 다중 동시발음 많을 때 CPU는 추후 측정.
- 키 cutoff key = wav id(IIDX식 동일 키음 컷). 채널별 세분(id*256+pitch)은 추후.
