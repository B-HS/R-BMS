# 기본 스킨 실화면 확인 누락

## 지적

사용자는 실행 화면 캡처를 보여주며 사진과 비교해 제대로 구현됐는지 물었다. 이전 화면은 선택 상세와 목록의 좌우가 뒤집혀 있었고, 옵션 패널에서 배경 글자가 비쳤으며, 재생 장식이 필드·영상·수치를 침범했다.

## 원인과 수정

문서 파싱과 파일 설치 검사만으로 시각적 완료를 판단했다. 문서 좌표와 실제 적용 프리셋의 좌표가 서로 다른데도 1280×720 출력 결과를 보지 않았다. 이번 보정은 번들·배치·레이어를 함께 수정하고 선택/옵션/5·7·9·10·14키/결과를 헤드리스로 렌더해 PNG를 직접 확인했다. 기록과 캡처는 `docs/history/2026-09-17-skin-visual-correction.md`와 `docs/quality-assurance/2026-09-17-default-skin/`에 둔다. 헤드리스 캡처가 실제 창의 GPU/입력 확인을 대신하지는 않는다.

## 적용 시점

스킨의 위치·크기·합성·글자 가독성을 바꿀 때마다 대표 모드 화면을 실제 렌더한 뒤 픽셀 배치와 정보 가림 여부를 보고 완료를 판단한다.

보편 규칙 승격 후보: 있음. 화면 변경은 컴파일 성공과 별도로 렌더 결과를 확인해야 한다는 일반 시각 검증 원칙이며, 승격 여부는 사용자 확인을 기다린다.
