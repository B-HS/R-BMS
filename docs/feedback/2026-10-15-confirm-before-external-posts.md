# 외부 게시는 초안을 보여 주고 승인받은 뒤에

최종 갱신 2026-10-15 · 대응 커밋 ea698a9

## 무엇을 지적받았나

2026-10-15. THR2-1(wgpu Metal 의 메인 스레드 위반) 결정에서 사용자가 A(구조 유지, ADR·QA 기록, 상류 이슈)를 골랐고, 메인이 초안을 보여 주지 않고 https://github.com/gfx-rs/wgpu/issues/10627 을 바로 올렸다. 사용자 원문: "뭐야 이슈를 왜 멋대로 올린거야".

## 왜 틀렸나

- 이슈는 사용자 계정으로 공개 저장소에 남는 글이라 되돌릴 수 없다. 추천안 문구 안의 "이슈를 올립니다"를 고른 것은 방향의 승인이지 게시 승인이 아니다.
- 본문에 감사 보고의 문장을 확인 없이 옮겨 부정확한 내용이 들어갔다("Main Thread Checker reports on every frame" — 실제로는 같은 호출 지점을 한 번만 보고한다. 코드 경로는 매 이미지마다 실행된다).

## 어떻게 고치나

외부 게시가 필요하면 주장마다 직접 확인한 근거로 초안을 쓰고, 초안 전문을 사용자에게 보여 주고, 명시적 승인 뒤 게시한다. 답글·본문 수정도 같다.

## 언제 적용하나

GitHub 이슈·댓글·PR, 다른 저장소·포럼·외부 서비스에 남는 모든 글. 이 저장소의 커밋·푸시·draft 릴리스(사용자가 정한 자동 절차)는 해당하지 않는다.

## 이번 건의 처리

이슈에 `bug` 라벨이 붙었고 답변(objc2 의 MainThreadMarker 관련)이 달렸다. 사용자 결정으로 그대로 둔다(2026-10-15).
