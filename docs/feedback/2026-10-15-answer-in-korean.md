# 긴 작업 중의 상태 보고도 한국어로

최종 갱신 2026-10-15 · 대응 커밋 ea698a9

## 무엇을 지적받았나

2026-10-15. 긴 작업(백그라운드 에이전트 대기, 커밋 보고) 중 사용자에게 보이는 상태 보고가 영어로 바뀌었다. 사용자 원문: "대답은 한글이여야지 영어로 바귀었네", 이어서 "한글 리스폰스다. 두번째말한다".

## 왜 틀렸나

사용자의 전역 컨벤션이 모든 응답을 한국어 존댓말로 정해 둔다. 첫 지적 뒤에도 같은 세션에서 한 번 더 어겼다. 짧은 상태 보고는 길이가 짧아 언어를 점검하는 대상으로 느껴지지 않았고, 하위 에이전트 보고와 도구 출력이 영어인 채 쌓인 긴 컨텍스트에서 그것이 응답의 언어로 번졌다고 본다(원인은 재현해 확인하지 못했다).

## 어떻게 고치나

응답을 보내기 전에 본문 언어를 본다. 코드 식별자, 명령, 경로만 원문으로 둔다. 도구 결과가 영어여도, 컨텍스트가 길어져도 응답 언어를 바꾸지 않는다.

## 언제 적용하나

항상. 특히 백그라운드 알림 뒤의 짧은 보고, 커밋 직후의 한 줄 보고, 하위 에이전트 결과를 옮기는 문장.
